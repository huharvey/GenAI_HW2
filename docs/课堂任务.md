# 课堂任务：实现一个可复核的多智能体技术调研助手

## 基础要求

1. 成功运行基础版。
2. 更换一个与本课程相关的主题。
3. 在 `trace.jsonl` 中找到一次工具调用和一次 Agent 间消息传递。
4. 检查报告中的 `[S#]` 是否都能在 `evidence_registry.json` 中找到。

## 提高要求

1. 成功运行提高版。
2. 修改 ReviewerAgent 的检查规则。
3. 让系统至少产生一次“通过”或“需要修改”的明确结果。
4. 比较修改前后的报告质量和运行轮数。

## 可选挑战

- 增加一个事实核查 Agent。
- 让 SearchAgent 只使用某一类来源。
- 把固定的 Planner → Searcher → Writer 改成另一种路由。
- 添加一个只读 MCP 工具，并说明它与 AutoGen 框架的分工。

## 建议评分

| 项目 | 比例 | 关注点 |
|---|---:|---|
| 能运行 | 25% | 环境配置、API 调用和结果保存 |
| Agent 分工 | 25% | 角色职责是否清楚，是否重复 |
| 工具与证据 | 25% | 是否使用真实工具，引用能否追溯 |
| 可靠性分析 | 25% | 是否设置终止、审阅和人工复核 |
